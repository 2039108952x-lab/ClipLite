## 简介

ClipLite 是一款 **极致轻量化 + 秒开体验 + 无广告绿色便携** 的 Windows 剪贴板管理器。

旨在替代 Windows 原生剪贴板（Win+V），解决单次复制覆盖文本内容的核心痛点。基于 C# + WinForms + .NET Framework 4.8 构建，依赖系统自带运行时，即下即用。

| 指标     | 目标值    | 实际值     |
| -------- | -------- | -------- |
| EXE 体积 | < 1 MB   | **约 82 KB** |
| 后台内存 | 6~12 MB  | 实测约 8~10 MB（GC 稳定后） |
| 启动时间 | < 200 ms | **< 50 ms** |
| 热键唤起 | < 50 ms  | **即时**（窗口预创建） |
| CPU 占用 | 0%       | **0%**（消息驱动，无轮询） |

## 功能说明

### 1. 自动剪贴板监听

- 监听系统级剪贴板变化事件（`WM_CLIPBOARDUPDATE`），**零 CPU 轮询**
- 文本内容被复制时自动保存到历史列表
- 可在设置中开启复制提示：普通复制与从历史复用都会显示轻量浮层
- 最多保存 **500 条** 记录，超出时自动移除最旧条目

### 2. Hash 去重 + 防回写

- 每条文本通过 **SHA256 取前 16 位** 生成唯一指纹
- 相同内容不会被重复添加，仅移 **至列表顶部**（最近使用优先）
- 从 ClipLite 选中复制时自动跳过本次回写，产生死循环

### 3. 全局热键唤起

默认 `Ctrl + Shift + V`，可在「设置 → 全局快捷键」中改键或关闭。

| 操作 | 快捷键 |
| ---- | ---- |
| 打开/隐藏历史面板 | `Ctrl + Shift + V`（默认，可配置） |
| 关闭面板 | `Esc` |
| 选中下一条 | `↓` 方向键（聚焦列表框后） |
| 选中上一条 | `↑` 方向键 |
| 删除当前条目 | `Delete` |
| 置顶 / 取消置顶 | `Ctrl + P` |
| 切换到搜索框 | `↓`（搜索框聚焦时落入列表） |

- 热键通过 Win32 `RegisterHotKey` 注册，全局生效
- 历史面板在启动时 **预先创建**，热键按下时立即显示
- 改键后立即重新注册；被其他程序占用时托盘会弹出提示

### 4. 一键复用

- **单击** 条目即可复制（无需双击），或按回车键
- 自动复制该条目内容到剪贴板，可选用轻量浮层提示（不依赖系统通知中心）
- 提示位置可切换：**跟随复制内容** 或 **屏幕底部**
- 鼠标悬停显示复制 / 删除按钮，右键菜单支持复制、置顶、删除
- 面板自动隐藏，直接 `Ctrl + V` 粘贴
  - 无需额外操作，极速工作流

### 5. 全文搜索与筛选

- 面板顶部搜索框，**输入即搜**（实时过滤）
- 不区分大小写，匹配文本、文件路径、富文本预览和类型名
- 搜索命中片段会黄色高亮
- 支持按类型筛选：全部 / 文本 / 图片 / 文件 / 富文本 / HTML
- 搜索结果依然保留置顶排序

### 6. 缩略图与置顶管理

- 图片条目异步生成缩略图，列表直接预览，不阻塞界面
- 置顶条目显示 **橙色「置顶」标记**，并永久排在列表顶部
- 右键菜单或 `Ctrl + P` 置顶 / 取消置顶

### 7. 托盘后台驻留

- 启动后静默运行于系统托盘
- 托盘右键菜单：

| 菜单项 | 功能 |
| ------ | ---- |
| 显示历史 | 弹出历史面板 |
| 暂停监听 | 停止收集新的剪贴板内容 |
| 恢复监听 | 恢复收集 |
| 清空历史 | 确认后清除所有记录 |
| 设置 | 打开设置窗口（热键、抓取模式、排除程序、加密等） |
| 退出 | 完全退出程序 |

- 托盘图标 **双击** 也弹出历史面板
- 图标为蓝色剪贴板，视觉辨识度高

### 8. 数据持久化

- 历史记录保存至 exe 同级目录下的 `cliplite_data/`
- `index.jsonl` 为 JSON Lines 索引，`assets/` 存放图片、RTF、HTML 等大对象
- 索引采用原子写入，并保留 `index.bak1~3.jsonl` 三份滚动备份
- 启用「加密存储」后索引以 AES-256 加密（文件头 `ENCR`）；assets 仍为独立文件
- 设置保存在 exe 同级的 `cliplite_settings.json`

## 快速开始

### 方法一：直接运行

```
ClipLite\ClipLite.exe
```

启动后托盘出现蓝色图标，按 `Ctrl + Shift + V` 即可调出历史面板。

### 方法二：自行编译

```bat
cd ClipLite
build.bat
```

编译产物为 `ClipLite.exe`（约 82 KB）。

**环境要求：** Windows 10/11（自带 .NET Framework 4.8），无需任何额外安装。

## 常见问题

**Q：如何修改热键？**  
打开托盘菜单「设置 → 全局快捷键」，点击输入框后按下新组合键；按 `Backspace` 可关闭全局热键。

**Q：最多能存多少条历史？**  
默认 500 条。在 `Models.cs` 中修改 `MaxEntries` 常量可调整上限。

**Q：历史数据文件在哪？**

与 `ClipLite.exe` 同目录，位于 `cliplite_data/`（`index.jsonl` + `assets/`）。
删除整个 `cliplite_data` 文件夹即可清空历史记录（下次启动自动重建）。

**Q：如何开机自启？**  
创建 `ClipLite.exe` 的快捷方式，放入 `shell:startup` 启动文件夹。
